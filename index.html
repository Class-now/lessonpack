LessonPack

Paste a short language lesson. Get one small HTML file that a learner can open on an old shared phone with no data: sent by Bluetooth, USB cable, SD card or a messaging app. It has read-aloud, a self-check quiz, large text, high contrast and easy-read spacing, and it saves progress on the phone.

Everything happens in this page. Nothing you type is uploaded. After one visit this page also works offline.

1. Write or paste the lesson

Plain text. Start with a title, then any of the sections [Vocabulary], [Dialogue], [Reading], [Questions]. See the format guide below.

2. Share the file

Your lesson file will appear here.

Format guide

Show the lesson format (one example of every line type) 
Title: At the Train Station
Language: en-US        (language being learned; used for read-aloud)
Notes language: ja     (language of the translations, optional)
Interface: ja          (buttons and instructions: en, ja or es)
Level: Beginner (A1)
Intro: One sentence about the lesson.

[Vocabulary]
ticket = 切符 | One ticket to Green Park, please.
(word = meaning | example sentence; meaning and example are optional)

[Dialogue]
Mika: Where is platform 3? = 3番ホームはどこですか？
(Speaker: line = translation; speaker and translation are optional)

[Reading]
The station is small but busy. = 駅は小さいけれど混んでいます。

[Questions]
Q: Where is platform 3?
+ Next to the stairs      (+ marks the one correct choice)
- Next to the shop        (- marks a wrong choice)
Why: The staff member says "next to the stairs".

Q: Where does Mika want to go?
A: Green Park | to Green Park   (typed answer; | separates accepted answers)

Command line (same engine): node cli.js lesson.txt

Getting the file to learners without data

  • Android: send the file by Bluetooth or Nearby Share, or copy it with a USB cable or SD card. Open it from Files in Chrome or the default browser.
  • iPhone: AirDrop the file, then open it from the Files app.
  • Messaging apps: send it as a document. The learner only needs data once to receive it; after that it works with no connection.
  • Paper: the lesson prints cleanly (answers included) for learners with no phone.
